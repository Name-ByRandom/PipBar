# DDC/CI 踩坑记录

配置显示器时可能遇到的问题。**通用规则**和**特定显示器的个案**分开写。

---

## 通用规则

### 读数必须做完整校验

DDC/CI 读回 8 字节响应，**必须全部校验**，缺一不可：

```
reply[0] == 0x6E      源地址
reply[2] == 0x02      Get VCP Feature Reply
reply[3] == 0x00      无错误
reply[4] == 请求的码   回显校验 ← 最重要
checksum: 0x50 XOR reply[0..9] == reply[10]
max != 0
```

少任何一条都会读到 EDID 残片或空帧。表现是读出无意义的值
（某些工具会返回 `110` 这种哨兵值）。

**判断通道是否健康，用亮度（`0x10`）读数当探针** —— 它几乎所有显示器都支持。

### 写入必须节流

连续快速写入会让部分显示器的 DDC 控制器堵死（完全无响应）。
建议所有 DDC 读写走**单条串行队列**，两次写入间隔 ≥150ms。

**别用"写完立刻读回"判断写入成功** —— 显示器切画面瞬间 DDC 会短暂失联。

### 读写不能并发

`IOAVServiceRef` 是裸指针。两个线程同时用会拿到野指针，导致崩溃。

### I/O 不能在主线程

- 显示器发现（遍历 IORegistry）：几百毫秒
- 每次 DDC 读（等回包）：~40ms
- 完整读一轮（7 项）：~350ms

跑在主线程会冻结界面。

### 热插拔会让缓存指针失效

拔插显示器后 macOS 重新枚举 IORegistry，旧的 DDC 通道对象被释放。
缓存的指针变成野指针 → 后续所有操作静默失败。

必须在拔插后**重新发现通道**。AppKit 的
`didChangeScreenParametersNotification` 在部分显示器热插拔时不触发，
所以还要监听 `CGDisplayRegisterReconfigurationCallback`，
并在写入失败时主动丢弃缓存重连。

### 怎么测码表

1. 跑 `ddcwatch watch`
2. 用显示器**实体按键**在 OSD 里逐个切换
3. `ddcwatch` 会实时打印每次变化对应的 VCP 码

**这是唯一可靠的方法。** 文档里的码值可能对特定型号是错的。

## 案例

以下是实测记录，仅对特定型号成立。**你的显示器可能完全不同**，
遇到了再往该显示器的配置档 `quirks` 数组里补。

### 某 Dell 34" 曲面（2022 款）

- **PIP/PBP 码值与第三方工具文档不符。** 某工具文档标注
  `43`/`44` 为 26:74/74:26，本机实测这两个值被显示器**直接拒绝**
  （写入后读回原值不变）。实际可用的是另一组值。
  → **教训：不要信任任何工具文档里的显示器码表。**
- **输入源码在两个字节里各放一遍。** 读 `0x60` 时 USB-C 返回
  `0x1B1B`（27 重复两遍），而非标准的 `0x001B`。
  → **处理：取低位字节 `value & 0xFF`。**
- **`0xE9`（PIP 模式）的 max 恒为 255**，实际可用值远小于此。
  不能用 max 做范围校验。
- **静音码 `0x8D` 的 max 是 65535**，不是常见的 1/2。
  判断静音看 `current == 1`。
- **DDC 写入会自动关闭 OSD 菜单；OSD 菜单开着时 DDC 流量会把控制器
  彻底写聋**（完全无 I2C ack）。
  → 恢复：① 打开一次 OSD 菜单 ② 拔插视频线 ③ 断电 10 秒（待机不够）。

完整配置见 [profiles/DELL S3423DWC.json](profiles/DELL S3423DWC.json)。

## 配置档字段说明

`shared/profiles/<EDID 显示器名>.json`：

| 字段 | 解析代码是否读取 | 说明 |
|---|---|---|
| `profile.edidName` | ✅ | 匹配键（缺省用文件名） |
| `profile.vendor` / `model` | ✅ | 界面显示用 |
| `profile.vendorIdHex` | ✅ | 多显示器时用来挑选通道 |
| `pbpModes.modes[]` | ✅ | PIP 布局码表 |
| `inputs[]` | ✅ | 视频输入；留空则用通用五个 |
| `quirks[]` | ❌ 仅供人读 | 踩坑记录，代码不解析 |
| `profile.connection` 等 | ❌ 仅供人读 | 备注信息 |
| `readValidation` | ❌ 仅供人读 | 协议规范备注 |
